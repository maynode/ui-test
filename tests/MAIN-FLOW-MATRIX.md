## 与 Smoke / Regression / Destructive 的对应

| 门禁 | 能回答 | 不能回答 |
|------|--------|----------|
| **Smoke**（8 条） | 课程/认证详情能开、能进学习、考试入口或终态、团队页、NCRE、伙伴页 | 交卷、视频文档、团队分配、发证 |
| **Regression**（11 条） | 多状态识别、折叠/名额入口、未登录与非 partner 拦截 | 固定多状态账号、跨页同步、购买 |
| **Destructive**（1 条） | 完整前置 + 客观题交卷 | 文件题、重复跑环境重置 |

## 建议补齐顺序（与 backlog 对齐）

```
1. P0 加深（改现有 spec）
   - 课程：TC-COURSE-002 断言 video / 文档节点
   - 认证：TC-CERT-006 进入模拟测试；005 固定账号拆状态；003/004 有数据断言行
   - 团队：名额页内分配一步（需 admin 已有团队）
   - 伙伴：立即学习 → 课程详情页

2. P1 新用例
   - 团队商城购买 → 记录同步
   - 未注册账号占位分配
   - 认证列表页加载

3. P2 造数
   - SEED-EXAM-STATE-001 → 固定考试 UI
   - SEED-CERT-PUBLISH-001 → 证书非空 + 发证断言
   - SEED-TEAM-001（待商城/订单调研）
```
